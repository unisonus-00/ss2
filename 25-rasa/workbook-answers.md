# Stage 25: Rasa — Workbook (Answers)

## Section A
1. **Śānta** (dhyāna, nirañjana, nirguṇa = peace vocabulary)
2. **Adbhuta** (aho!, ko'yam = wonder exclamations)
3. **Karuṇa** (dīna, trāhi, duḥkha = compassion/sorrow)
4. **Vīra** (jayati, vīra, tripurāntaka = heroic)
5. **Śṛṅgāra** (sundara, ramate, kailāse = beauty/love)

## Section B — Samples for Śiva
**B1.** Śānta: nityo nirmalaḥ nirguṇaḥ sadāśivaḥ / akhaṇḍānanda-rūpaḥ svayam-prakāśaḥ / tasmin dhyāna-sthite sarvaṃ śāntam
**B2.** Vīra: jayati tripurāntakaḥ! jayati saṃhāra-mūrtiḥ! / triśūla-hasta ugra-rūpaḥ śivaḥ asurān nihanti!
**B3.** Karuṇa: he kṛpālo! he dayānidhe! / dīno'smi, ārtaḥ asmi, trāhi mām / tava kṛpā vinā ko me śaraṇam?
**B4.** Adbhuta: aho! kīdṛśaṃ rūpam! ardhaṃ strī ardhaṃ puruṣaḥ! / viṣaṃ pītvā nīlakaṇṭhaḥ — ko'yaṃ prabhāvaḥ!
**B5.** Śṛṅgāra: candra-mukhāḥ smita-sundaraḥ / pārvatyā saha mandāra-vane viharati / manda-vātena jaṭā calanti

## Section C
Accept any well-reasoned analysis. Example: Rudram (Śrī Rudram) — dominant rasa is **Adbhuta** mixed with **Bhayānaka** and **Śānta**. Vocabulary includes ugra, bhīma, ghora (fearful) but also śiva, śānta, mayaskara (benevolent). The Vedic triṣṭubh meter provides power. Paradoxical descriptions (terrible yet benign) create sustained wonder.

## Section D — Samples
**Śānta:** namāmi śivaṃ nityaṃ nirañjanam / dhyāna-sthitam ākāśa-sadṛśam / sarvam asya praśāntam
**Vīra:** namāmi śivaṃ saṃhāra-mūrtim / yasya triśūla-prasāreṇa asuratrayam naṣṭam / jayati mahāvīraḥ!
**Karuṇa:** namāmi śivaṃ karuṇā-sindhum / he dīna-bandho! mama duḥkhaṃ paśya / tava caraṇe patito'smi
**Adbhuta:** namāmi śivam — aho adbhutam! / yaḥ viṣam pītvā amṛtaṃ dadāti / yasya ardhāṅge devī vasati — kiṃ citraṃ!
