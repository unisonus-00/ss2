# Stage 19: Chandas I — Reference Guide

## Laghu/Guru Rules

| Condition | Result | Example |
|-----------|--------|---------|
| Long vowel (ā,ī,ū,e,ai,o,au) | Guru (–) | nā, de, vai |
| Short vowel + single C + vowel | Laghu (∪) | na, ma, ka |
| Short vowel + conjunct | Guru (–) | bha in bhaktyā |
| Short vowel + anusvāra | Guru (–) | saṃ, taṃ |
| Short vowel + visarga | Guru (–) | namaḥ (maḥ = –) |
| Last syllable of pāda | Guru (by convention) | always – |

## 8 Gaṇas

| Name | Pattern | Mnemonic (from yamātārājabhānasalagām) |
|------|---------|----------------------------------------|
| ya | ∪ – – | **ya**-mā-tā |
| ma | – – – | **mā**-tā-rā |
| ta | – – ∪ | **tā**-rā-ja |
| ra | – ∪ – | **rā**-ja-bhā |
| ja | ∪ – ∪ | **ja**-bhā-na |
| bha | – ∪ ∪ | **bhā**-na-sa |
| na | ∪ ∪ ∪ | **na**-sa-la |
| sa | ∪ ∪ – | **sa**-la-gā |

Plus single-syllable units: **la** (∪) and **ga** (–)

## Scansion Notation

Use ∪ for laghu and – for guru. Write the pattern below each syllable:

```
na  mā  mi  śi  vam  śān  tam  de  vam
∪   –   ∪   ∪   –    –    –    –   –
```
