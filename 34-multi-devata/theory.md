# Stage 34: Multi-devatā — Rapid Semantic Switching

## Goal
Switch between deity lexical worlds instantly — Śiva → Lalitā → Kṛṣṇa → Sarasvatī — each requiring completely different vocabulary, rasa, epithets, and associations.

## The Challenge

In avadhāna, different pṛcchakas may assign different deities to different compositions. You might be simultaneously composing:
- A śānta-rasa Śiva verse (no "na")
- A vīra-rasa Durgā verse (with required word "sindhu")
- A śṛṅgāra-rasa Kṛṣṇa verse (in vasantatilakā)
- A karuṇa-rasa Rāma verse (samasyāpūraṇa)

Each time you switch between these, your entire mental vocabulary must shift.

## Eight Darśanas Drill

Rapidly compose ONE pāda for each of 8 deities in sequence:

1. **Śiva** → kaivalya, hara, kailāsa, tṛtīya-netra...
   → pāda: ___

2. **Lalitā** → śṛṅgāra, māṇikya, kāmakalā, bindu...
   → pāda: ___

3. **Kṛṣṇa** → veṇu, gopī, vṛndāvana, pīta-ambara...
   → pāda: ___

4. **Sarasvatī** → vīṇā, pustaka, haṃsa, śveta...
   → pāda: ___

5. **Durgā** → siṃha, khaḍga, mahiṣa, aṣṭa-bhuja...
   → pāda: ___

6. **Gaṇeśa** → modaka, mūṣaka, siddhi, ekadanta...
   → pāda: ___

7. **Hanumān** → vāyu-putra, rāma-dāsa, laṅkā, parvata...
   → pāda: ___

8. **Sūrya** → ratha, saptāśva, divākara, prabhā...
   → pāda: ___

## Semantic World Boundaries

Each deity has a "world" — a set of associated words that belong together:

| Deity | Exclusive Vocabulary |
|-------|---------------------|
| Śiva | liṅga, bhasm, ḍamaru, gaṅgā-jaṭā, nandī, kailāsa, pināka |
| Kṛṣṇa | veṇu, gopī, makhan, yamunā, vṛndāvana, rāsa |
| Durgā | siṃha-vāhana, khaḍga, mahiṣa, caṇḍī, navadurgā |
| Sarasvatī | vīṇā, pustaka, haṃsa, akṣamālā, śveta-padma |
| Rāma | kodaṇḍa, vānara, sītā, ayodhyā, setubandha |
| Gaṇeśa | ekadanta, modaka, mūṣaka, siddhi-buddhi |
| Hanumān | giridhārī (different from Kṛṣṇa's!), rāmadāsa, laṅkā-dāha |

## The Mixing Error

The biggest danger: accidentally using Kṛṣṇa vocabulary in a Śiva verse. "Veṇu-vadana" for Śiva would be a blunder. Maintain strict boundaries.

## Speed Training

| Level | Challenge |
|-------|-----------|
| 1 | Switch between 2 deities every 2 minutes |
| 2 | Switch between 4 deities every minute |
| 3 | Switch between 8 deities every 30 seconds |
| 4 | Random deity calls — respond with 1 pāda in 15 seconds |

## Milestone Check
Can you produce one pāda for each of 8 different deities, switching between them with no vocabulary contamination?
