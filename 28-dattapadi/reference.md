# Stage 28: Dattapadī — Reference Guide

## Integration Techniques Summary

| Technique | How | Example |
|-----------|-----|---------|
| Upamā | "like X" | tava kṛpā megha iva varṣati |
| Rūpaka | "X IS Y" | bhakti-nauka, jñāna-dīpa |
| Direct attribute | deity has/is X | siṃha-rūpa narasiṃha |
| Philosophical | X symbolizes Y | dīpa = jñāna, tamas = ajñāna |
| Narrative | place in story | megha garjati → deity appears |
| Negation | "even X cannot..." | sindhur api na tava mahimā |
| Vocative | address deity as X | he jñāna-dīpa! |

## Universal Connectors (How to link any word to devotion)

| Seemingly unrelated word | Devotional connection via... |
|--------------------------|------------------------------|
| Any animal | vehicle (vāhana), form (avatāra), or simile |
| Any natural object | simile for deity's quality |
| Any tool/object | metaphor for spiritual aid |
| Any place | where deity's līlā occurred |
| Any abstract concept | philosophical attribute |
| Any negative concept | what deity removes/conquers |
