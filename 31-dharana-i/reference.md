## Memory Strategies

| Strategy | How |
|----------|-----|
| First-word chain | Remember: śāntam-jagad-govinda-siddhi |
| Rhythmic humming | Hum the meter of each pāda |
| Semantic arc | "peace → mother → flute → elephant" |
| Spatial placement | Place each in a corner of a mental room |
| Body anchoring | Touch head/heart/navel/feet for 1/2/3/4 |

## Common Errors and Prevention

| Error | Prevention |
|-------|-----------|
| Confusing pādas between slots | Distinct deity anchors |
| Forgetting exact words | Remember first 2 words minimum |
| Meter drift on continuation | Re-chant the rhythm before continuing |
| Semantic inconsistency | Remember the "story arc" of each verse |
