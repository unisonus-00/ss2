# Stage 31: Dhāraṇā I — Workbook (Questions)

## Exercise 1: Two Threads (20 marks)
**Round 1:** Compose pāda (a) for two stotras:
1. Śiva stotra, pāda a: ___
2. Devī stotra, pāda a: ___

**Now close this book. Wait 5 minutes. Do something else.**

**Round 2:** WITHOUT looking back, write pāda (a) from memory, then add pāda (b):
1. Śiva: a (recalled): ___ → b: ___
2. Devī: a (recalled): ___ → b: ___

**Round 3:** Recall a+b, add c and d:
1. Śiva: complete śloka: ___
2. Devī: complete śloka: ___

## Exercise 2: Four Threads (30 marks)
**Round 1:** Compose pāda (a) for four stotras (4 different deities):
1. ___ 2. ___ 3. ___ 4. ___

**PAUSE 10 minutes.**

**Round 2:** Recall all four pāda (a)s and add pāda (b):
1. a: ___ → b: ___
2. a: ___ → b: ___
3. a: ___ → b: ___
4. a: ___ → b: ___

**PAUSE 5 minutes.**

**Round 3-4:** Complete all four ślokas.

## Exercise 3: Self-Assessment (10 marks)
After completing Exercise 2, compare your recalled pāda (a)s with what you originally wrote. Score yourself:
- Perfect recall = 2 marks each
- Minor change (1-2 syllables different) = 1 mark each
- Forgot / major change = 0 marks each
