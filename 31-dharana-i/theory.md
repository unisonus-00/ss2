# Stage 31: Dhāraṇā I — Interrupted Memory

## Goal
Hold multiple unfinished compositions simultaneously in memory. Begin four different stotras, compose one pāda each, then return to complete them — maintaining each thread perfectly.

## What is Dhāraṇā?

**Dhāraṇā** (धारणा) = holding, retention. In avadhāna, you must hold multiple unfinished verses in memory while being interrupted by other challenges. This stage trains that memory muscle.

## The Exercise: One Pāda Offering

### Round 1: Begin four compositions
Compose pāda (a) for each of four different stotras:

1. **Śiva stotra:** śāntam divyam trilocanam
2. **Devī stotra:** jagadambāṃ prapadye tām
3. **Kṛṣṇa stotra:** govindaṃ veṇuvādinam
4. **Gaṇeśa stotra:** siddhidaṃ gaṇanāyakam

Now STOP. Do something else. Come back later.

### Round 2: Add pāda (b) to each
Return and continue each without re-reading pāda (a):

1. **Śiva:** [recall pāda a] → add pāda b
2. **Devī:** [recall pāda a] → add pāda b
3. **Kṛṣṇa:** [recall pāda a] → add pāda b
4. **Gaṇeśa:** [recall pāda a] → add pāda b

### Rounds 3-4: Complete with pādas (c) and (d)

## Memory Techniques

### 1. Anchoring
Associate each composition with a distinct mental image:
- Śiva stotra → image of Kailāsa
- Devī stotra → image of the yantra
- Kṛṣṇa stotra → image of Vṛndāvana
- Gaṇeśa stotra → image of the modaka

### 2. Rhythmic Memory
Each pāda has a distinct rhythm. Memorize the SOUND, not just the words.

### 3. Semantic Chunking
Remember the meaning-arc, not just individual words:
"I started with peaceful-divine-three-eyed → next should describe form/action"

### 4. First-Word Triggers
Remember just the first word of each pāda: śāntam → jagadambām → govindam → siddhidam
