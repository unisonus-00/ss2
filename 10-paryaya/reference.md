## Epithet-Building Patterns

| Pattern | Formula | Examples |
|---------|---------|----------|
| Quality + Body part | adj + noun | nīlakaṇṭha, raktanetra |
| Object + Bearer | noun + √dhṛ | gaṅgādhara, śārṅgadhara |
| Number + Feature | num + noun | trilocana, caturbhuja |
| Action + Object | √verb + noun | tripurāntaka, madanāri |
| Relation + Title | name + pati/suta | umāpati, daśarathasuta |
| Location + Lord | place + īśa/nātha | kailāsanātha, kedāranātha |
