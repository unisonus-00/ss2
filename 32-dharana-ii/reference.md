# Stage 32: Dhāraṇā II — Reference Guide

## Quick-Access Deity Banks

### Śiva — Instant Access
Epithets (2-syl): hara, īśa, bhava
Epithets (3-syl): śambhu, śaṅkara, rudra
Epithets (4-syl): maheśvara, tryambaka, nīlakaṇṭha
Bhāva starters: śānta→dhyānasthita, vīra→tripurāntaka, karuṇa→dīnabandho

### Devī — Instant Access
Epithets (2-syl): ambā, śakti
Epithets (3-syl): durgā, gaurī, umā
Epithets (4-syl): jagadambā, pārvatī, bhavānī
Bhāva starters: śānta→caitanya, vīra→mahiṣāsura-mardinī, karuṇa→he mātar

### Viṣṇu/Kṛṣṇa — Instant Access
Epithets (2-syl): hari, kṛṣṇa
Epithets (3-syl): govinda, mādhava
Epithets (4-syl): nārāyaṇa, vāsudeva, janārdana
Bhāva starters: śānta→yoganidrā, vīra→narasiṃha, karuṇa→dīnavatsala

## Retrieval Speed Test Format

```
CUE: [Deity] + [Bhāva] + [Meter] + [Constraint]
TARGET: 1 pāda within ___ seconds
```

## Associative Chain Diagram

```
TRIGGER (e.g., "Śiva")
    ↓ (< 1 sec)
VOCABULARY SET activated
    ↓ (+ bhāva cue)
WORD FILTER applied (rasa vocabulary)
    ↓ (+ meter cue)
PROSODIC FILTER applied (syllable count/pattern)
    ↓ (+ constraint)
PROHIBITION FILTER applied (forbidden letter check)
    ↓
OUTPUT: pāda
```
