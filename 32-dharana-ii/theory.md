# Stage 32: Dhāraṇā II — Associative Retrieval

## Goal
Retrieve poetic states from cues. Given a deity → instantly recall the bhāva → select the meter → apply the constraint → produce the pāda. Build rapid associative chains.

## The Chain: Deity → Bhāva → Meter → Constraint → Pāda

In avadhāna, you don't have time to think sequentially. You must build **automatic associations**:

### Level 1: Deity → Vocabulary Set
Hear "Śiva" → instantly access: hara, śambhu, trilocana, gaṅgādhara, kailāsa, bhasm, jaṭā, tṛtīya-netra, nandī, ḍamaru...

### Level 2: Bhāva → Sentence Type + Word Choice
Hear "karuṇa" → plea structure, dīna/ārt vocabulary, trāhi/pāhi verbs, mandākrāntā meter preference

### Level 3: Meter → Automatic Pattern
Hear "anuṣṭubh" → 8 syllables, positions 5-6-7 in even pādas, yati after 4

### Level 4: Constraint → Avoidance/Inclusion Set
Hear "no na" → instant mental filter activating: use bhaj not nam, use indu not candra...

## The Deity Memory Palace

Build a mental structure for each deity containing:

```
ŚIVA
├── Epithets: [hara, śambhu, tryakṣa, maheśvara...]
├── Objects: [triśūla, ḍamaru, bhasm...]
├── Stories: [hālāhala, gaṅgā, tripura, tāṇḍava...]
├── Bhāva-ready phrases:
│   ├── Śānta: dhyāna-sthita nirañjana...
│   ├── Vīra: tripurāntaka saṃhāramūrti...
│   ├── Karuṇa: he kṛpālo dīnabandho...
│   └── Adbhuta: aho ardhanaṭeśvara...
├── Synonyms by syllable count: [hara(2), śambhu(2), maheśvara(4)...]
└── Prosodic profiles: [hara=∪∪, śambhu=––, maheśvara=∪–∪∪...]
```

## Retrieval Drills

### Drill 1: Flash Response
Someone says a deity name. Within 5 seconds, produce ONE epithet you haven't used recently.

### Drill 2: Bhāva Shift
Given "Śiva + vīra" — produce one line immediately.
Given "Śiva + karuṇa" — produce one line immediately.
Given "Śiva + śānta" — produce one line immediately.

### Drill 3: Constraint Chain
Given "Devī + anuṣṭubh + no sa" — produce one pāda within 30 seconds.

### Drill 4: Cue Reconstruction
You composed a verse about Kṛṣṇa yesterday. Cue: "veṇu". Can you recall and continue?

## Milestone Check
Given a deity name + bhāva + meter + one constraint, can you produce a pāda within 30 seconds?
