## Stotra Templates

### Template 1: Simple Namāmi (4 lines)
```
[epithet-acc] [epithet-acc] namāmi
[epithet-acc] [epithet-acc] namāmi
[epithet-acc] [epithet-acc] namāmi
[epithet-acc] [epithet-acc] namāmi
```

### Template 2: Bhaje + Epithets (verse)
```
[name-acc] [name-acc] [name-acc] [name-acc]
[name-acc] [name-acc] [name-acc] [name-acc]
[name-acc] [name-acc] [name-acc] [name-acc]
[name-acc] [name-acc] [name-acc] bhaje
```

### Template 3: Yaḥ/Yā Relative (who... him/her I bow to)
```
yaḥ [description] yaḥ [description]
yaḥ [description] yaḥ [description]
taṃ [deity-acc] [verb]
```

### Template 4: Alternating epithets + refrain
```
[line of description]
taṃ/tāṃ praṇamāmi (refrain)
[line of description]
taṃ/tāṃ praṇamāmi (refrain)
```
