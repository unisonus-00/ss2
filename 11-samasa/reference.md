# Stage 11: Samāsa — Reference Guide

## Compound Types at a Glance

| Type | Head | Meaning Pattern | Example |
|------|------|----------------|---------|
| Tatpuruṣa | 2nd word | "X of/by/for/in Y" | rāja-putra (king's son) |
| Karmadhāraya | 2nd word | "X which is Y" | mahā-deva (great god) |
| Dvigu | 2nd word | "number + Y" | tri-loka (three worlds) |
| Dvandva | both | "X and Y" | rāma-kṛṣṇau |
| Bahuvrīhi | external | "having X-Y" | nīla-kaṇṭha (blue-throated one) |
| Avyayībhāva | 1st word | adverb | prati-dinam (daily) |

## Tatpuruṣa Subtypes

| Subtype | Relation | Vigraha (dissolution) | Example |
|---------|---------|----------------------|---------|
| 2nd (dvitīyā) | toward | X-am Y | śaraṇāgata (come to refuge) |
| 3rd (tṛtīyā) | by/with | X-ena Y | deva-datta (god-given) |
| 4th (caturthī) | for | X-āya Y | yajña-śālā (sacrifice-hall) |
| 5th (pañcamī) | from | X-āt Y | bhaya-mukta (freed from fear) |
| 6th (ṣaṣṭhī) | of | X-asya Y | rāja-putra (king's son) |
| 7th (saptamī) | in | X-e Y | vana-vāsa (forest-dwelling) |

## Sandhi at Compound Junctions

| Rule | Example |
|------|---------|
| a + a → ā | deva + astra → devāstra |
| a + i → e | mahā + īśvara → maheśvara |
| a + u → o | nīla + utpala → nīlotpala |
| a + ṛ → ar | mahā + ṛṣi → maharṣi |
| t + vowel → d | jagat + ambā → jagadambā |
| t + soft consonant → d | sat + guru → sadguru |
| n + ś → ñś | mahān + śiva → — (rarely compounds) |

## Compound Identification Flowchart

1. Does the compound describe something OUTSIDE itself? → **Bahuvrīhi**
2. Is the first word an indeclinable? → **Avyayībhāva**
3. Are both members co-equal ("and")? → **Dvandva**
4. Is the first member a number? → **Dvigu**
5. Is the first an adjective for the second? → **Karmadhāraya**
6. Otherwise → **Tatpuruṣa** (determine the case relationship)
