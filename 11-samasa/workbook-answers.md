## Section B
**B1.**
1. gaṅgādhara → **gaṅgāṃ dharati yaḥ saḥ** (he who bears Gaṅgā) — Bahu.
2. tripurāntaka → **tripurasya antakaḥ** (destroyer of Tripura) — Tat.
3. padmanābha → **padmaṃ nābhau yasya saḥ** (he whose navel has a lotus) — Bahu.
4. jagadambā → **jagataḥ ambā** (mother of the world) — Tat.
5. cakrapāṇi → **cakraṃ pāṇau yasya saḥ** (discus in whose hand) — Bahu.
6. nīlotpala → **nīlam utpalam** (blue lotus) — Karm.
7. pañcabhūta → **pañca bhūtāni** (five elements) — Dvigu
8. dharma-artha-kāma-mokṣāḥ → **dharmaḥ ca arthaḥ ca kāmaḥ ca mokṣaḥ ca** — Dvandva
9. vanavāsa → **vane vāsaḥ** (dwelling in the forest) — Saptamī-tat.
10. sadguru → **san guruḥ** (true guru) — Karm.

**B2.**
1. ā + ī → **e** (vowel sandhi: ā+ī=e)
2. a + u → **o** (vowel sandhi: a+u=o)
3. t + a → **da** (consonant: final t before voiced → d)
4. t + g → **dg** (consonant: final t before voiced → d)
5. a + i → **e** (vowel sandhi: a+i=e)

## Section C
**C1.**
1. padma + akṣa = **padmākṣa** (type: **Bahuvrīhi** — lotus-eyed)
2. mahā + vidyā = **mahāvidyā** (type: **Karmadhāraya** — great knowledge)
3. sūrya + candra = **sūryacandau** (type: **Dvandva** — sun and moon)
4. tri + netra = **trinetra** (type: **Bahuvrīhi/Dvigu** — three-eyed)
5. vana + cara = **vanacara** (type: **Saptamī-Tatpuruṣa** — forest-wanderer)
6. rāja + haṃsa = **rājahaṃsa** (type: **Karmadhāraya** — royal swan)
7. śiva + pārvatī = **śivapārvatyau** (type: **Dvandva**)
8. pra + dinam = **pradinam** (type: **Avyayībhāva** — daily) [or pratitinam]
9. bhakta + vatsala = **bhaktavatsala** (type: **Saptamī-Tat.** — affectionate to devotees)
10. garuḍa + dhvaja = **garuḍadhvaja** (type: **Bahuvrīhi** — garuḍa-bannered)

**C2.** Sample new Bahuvrīhi epithets:
1. **raktanetra** = rakta + netra (red-eyed one) → Rudra/Bhairava
2. **hemakuṇḍala** = hema + kuṇḍala (gold-earringed) → Devī
3. **śukladhvaja** = śukla + dhvaja (white-bannered) → Sarasvatī
4. **daśabāhu** = daśa + bāhu (ten-armed one) → Durgā
5. **meghavarṇa** = megha + varṇa (cloud-complexioned) → Kṛṣṇa

## Section D
**D1.**
1. nīlakaṇṭha:
   - As Tatpuruṣa: **nīlaḥ kaṇṭhaḥ** = "a blue throat" (the object itself)
   - As Bahuvrīhi: **nīlaḥ kaṇṭhaḥ yasya saḥ** = "he whose throat is blue" (= Śiva)

2. rājaputra:
   - As Tatpuruṣa: **rājñaḥ putraḥ** = "a king's son" (the prince himself)
   - As Bahuvrīhi: **rājā putraḥ yasya saḥ** = "one whose son is a king"

**D2.**
śrīmad-rāma-bhadra-mūrti-pādāravinda-yugala-dhyāna-parāyaṇa:
- śrīmat = glorious
- rāma = Rāma
- bhadra = auspicious
- mūrti = form
- pāda = foot
- aravinda = lotus
- yugala = pair
- dhyāna = meditation
- parāyaṇa = devoted to

**Meaning:** "One devoted to the meditation upon the pair of lotus-feet of the auspicious form of glorious Rāma"
