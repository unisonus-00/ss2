# Stage 26: Darśana — Reference Guide

## Philosophical Vocabulary by Category

### Being/Reality: sat, satya, tattva, vastu, svarūpa, bhūta, padārtha
### Consciousness: cit, caitanya, bodha, prajñā, saṃvit, prakāśa
### Bliss: ānanda, sukha, hlāda, tuṣṭi, muda
### Non-duality: advaita, advaya, eka, kevala, kaivalya
### Transcendence: nirguṇa, nirākāra, nirañjana, nirmala, nirvikāra, niṣkala
### Immanence: saguṇa, sākāra, viśvarūpa, sarva-gata, antaryāmin
### Time: kāla, mahākāla, nitya, sanātana, anādi, ananta, kṣaṇa
### Power: śakti, parā, icchā, jñāna, kriyā, māyā, prakṛti, vibhūti
### Cosmology: sṛṣṭi, sthiti, saṃhāra, tirodhāna, anugraha

## Paradox Pairs for Poetic Use
| Pair | Meaning |
|------|---------|
| aṇu / vibhu | atomic / all-pervading |
| nirguṇa / saguṇa | qualityless / with qualities |
| nirākāra / viśvarūpa | formless / universal form |
| niṣkriya / sarvakartā | actionless / doer of all |
| śūnya / pūrṇa | empty / full |
| eka / aneka | one / many |
| dūra / antika | far / near |
| avyakta / vyakta | unmanifest / manifest |

## Model Philosophical Verses
### Dakṣiṇāmūrti Stotra (Ādi Śaṅkara):
> viśvaṃ darpaṇa-dṛśyamāna-nagarī-tulyaṃ nijāntargatam
> (The universe is like a city reflected in a mirror, contained within the self)

### Śvetāśvatara Upaniṣad:
> eko devaḥ sarvabhūteṣu gūḍhaḥ sarvavyāpī sarvabhūtāntarātmā
> (One god hidden in all beings, all-pervading, inner self of all beings)
