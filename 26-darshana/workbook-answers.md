## Section B
**B1.** Sample: caitanya-rūpa! tvaṃ sarvasya sākṣī / na tvaṃ dṛśyaḥ, kintu draṣṭā tvam eva / tava prakāśena jagatī bhāti / namo namo jñāna-svarūpāya

**B2.** Sample: aṇoḥ aṇīyān mahato mahīyān / dūre ca antike ca sadā vasasi / nirguṇaḥ saguṇaś ca tvam eva / nirākāraḥ viśvarūpaś ca tvam

**B3.** Sample: tvaṃ pṛthivī, tvaṃ āpaḥ, tvaṃ tejaḥ / tvaṃ vāyuḥ, tvaṃ ākāśam / tvaṃ sarvam idam viśvam

## Section C
**C1.** Sample: viśvaṃ darpaṇe nagarī iva [upamā] tava antare bhāti / tvaṃ caitanya-sindhuḥ [rūpaka], jagat taraṅgāḥ tava / sṛṣṭiṃ karosi līlayā, saṃhāram api līlayā / nirguṇaḥ saguṇaś ca eka eva tvam / aho māyā-vilāsa! [adbhuta-rasa] / namo namo advaya-brahmaṇe tubhyam

**C2.** Sample (Māyā): māyayā āvṛtaṃ jagat sarvaṃ / rajju-sarpa-nyāyena bhāti nānātvam / kintu eka-rūpaḥ tvam eva asti / māyāpatiṃ prapadye tam advayam
