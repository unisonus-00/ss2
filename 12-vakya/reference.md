# Stage 12: Vākya — Reference Guide

## Sentence Templates

### Existence: X asti (X exists / there is X)
> mandiram asti. devī asti. jalam asti.

### Identity: X Y asti (X is Y)
> śivaḥ devaḥ asti. sā mama mātā asti.

### Location: X Y-saptamī asti (X is in Y)
> mūrtiḥ mandire asti. puṣpam padme asti.

### Possession: X-ṣaṣṭhī Y asti (X has Y / X's Y exists)
> mama gṛham asti. devasya kṛpā asti.

### Action: S (+ O) + V
> aham gacchāmi. aham pustakam paṭhāmi.

### Full: S + Time + Place + Instrument + Recipient + O + V
> aham prātaḥ mandire bhaktyā devāya puṣpam arpayāmi.
