# Stage 7: Kāraka — Reference Guide

## Kāraka-Vibhakti Mapping

| Kāraka | Meaning | Vibhakti | Marker (M -a) | Question |
|--------|---------|----------|---------------|----------|
| Kartā | Agent | 1st (prathamā) | -aḥ | Who does? |
| Karma | Object | 2nd (dvitīyā) | -am | What is done? |
| Karaṇa | Instrument | 3rd (tṛtīyā) | -ena | By what means? |
| Sampradāna | Recipient | 4th (caturthī) | -āya | For whom? |
| Apādāna | Source | 5th (pañcamī) | -āt | From where? |
| Adhikaraṇa | Location | 7th (saptamī) | -e | Where? |
| (Sambandha) | Relation | 6th (ṣaṣṭhī) | -asya | Whose? |

## Sentence Building Template

```
[Kartā/1st] + [Karaṇa/3rd] + [Adhikaraṇa/7th] + [Sampradāna/4th] + [Karma/2nd] + [Kriyā/verb]
```

Example:
```
bhaktaḥ    bhaktyā    mandire    śivāya    puṣpam    dadāti
kartā      karaṇa     adhikaraṇa sampradāna karma     kriyā
```

## Kāraka Analysis Shorthand

Use these codes for quick analysis:
- K1 = Kartā (agent)
- K2 = Karma (object)
- K3 = Karaṇa (instrument)
- K4 = Sampradāna (recipient)
- K5 = Apādāna (source)
- K7 = Adhikaraṇa (location)
- V = Kriyā (verb)
- S6 = Sambandha (genitive relation)
