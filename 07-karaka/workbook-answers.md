# Stage 7: Kāraka — Workbook (Answers)

## Section A

**A1.**
1. bhaktaḥ → **Kartā** (agent)
2. devam → **Karma** (object)
3. puṣpeṇa → **Karaṇa** (instrument)
4. śivāya → **Sampradāna** (recipient)
5. mandire → **Adhikaraṇa** (location)

**A2.**
1. Kartā → **Prathamā (1st)**
2. Karma → **Dvitīyā (2nd)**
3. Karaṇa → **Tṛtīyā (3rd)**
4. Sampradāna → **Caturthī (4th)**
5. Apādāna → **Pañcamī (5th)**
6. Adhikaraṇa → **Saptamī (7th)**

**A3.** **Ṣaṣṭhī (6th / genitive)** is not a kāraka. It expresses **sambandha** (relation/possession), e.g., "śivasya mandiraṃ" (Śiva's temple). It does not describe a participant in the action.

## Section C

**C1.** **bhaktaḥ bhaktyā mandire stotram gāyati**
(The devotee sings a hymn with devotion in the temple)

**C2.** **devī kṛpayā bhaktam duḥkhāt rakṣati**
(The goddess protects the devotee from suffering with grace)

**C3.** Sample answers:

1. **bhaktaḥ bhaktyā mandire devam namati**
   K1=bhaktaḥ, K3=bhaktyā, K7=mandire, K2=devam

2. **bālaḥ premaṇā devāya puṣpam arpayati**
   K1=bālaḥ, K3=premaṇā, K4=devāya, K2=puṣpam

3. **yogī hṛdaye śivam dhyāyati**
   K1=yogī, K7=hṛdaye, K2=śivam

4. **mātā śraddhayā gṛhe dīpam jvālayati**
   K1=mātā, K3=śraddhayā, K7=gṛhe, K2=dīpam

5. **guruḥ āśrame śiṣyāya mantram dadāti**
   K1=guruḥ, K7=āśrame, K4=śiṣyāya, K2=mantram

## Section D

**D1.**
1. Emphasize puṣpam: **puṣpam bhaktaḥ devāya dadāti**
2. Emphasize śivaḥ: **śivaḥ bhaktam rakṣati** (already first — correct)
3. Emphasize mandire: **mandire bhaktaḥ dhyāyati** (already first — correct)

**D2.** **Yes**, all three mean the same thing: "I give a flower to Śiva." Because kāraka relations are encoded in the vibhakti endings (-āya = dative, puṣpam = accusative), the meaning is preserved regardless of word order. The difference is emphasis: the first position carries topical emphasis, and the pre-verbal position carries focus.
