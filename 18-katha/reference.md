## Narrative Structure Template

```
1. SETTING:    purā [kāle/deśe] [character] āsīt.
2. CHARACTER:  saḥ/sā [description] āsīt.
3. EVENT:      ekadā [event] abhavat.
4. ACTION:     saḥ/sā [action-past].
5. CRISIS:     kintu/tadā [problem] abhavat.
6. RESPONSE:   tataḥ [character] [response-past].
7. CLIMAX:     tadā [deity] [intervention-past].
8. RESOLUTION: evaṃ [result] abhavat.
9. MORAL:      ataḥ/tasmāt [lesson].
```

## Narrative Connectors (Sequence)

| Connector | Position | Meaning |
|-----------|----------|---------|
| purā | opening | long ago |
| ekadā | opening | once |
| ekasmin dine | opening | one day |
| tadā | mid | then |
| tataḥ | mid | after that |
| anantaram | mid | afterwards |
| atha | mid | now, then |
| kintu | mid | but |
| tathāpi | mid | even so |
| evaṃ | closing | thus |
| ataḥ | closing | therefore |
| iti | closing | thus (end) |

## Direct Speech Pattern
```
"[speech]" iti [speaker] avadat/prārthayat/cintayat
```
