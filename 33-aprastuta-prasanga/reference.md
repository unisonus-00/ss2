# Stage 33: Aprastuta-prasaṅga — Reference Guide

## Witty Response Templates

| Question Type | Response Pattern |
|--------------|-----------------|
| "Why does X do Y?" | "Because [philosophical reason], just as [analogy]" |
| "Which is greater, X or Y?" | "Both are aspects of [higher truth]" or give a clever disambiguation |
| Trick question | Acknowledge the trick: "The question itself contains the answer..." |
| Factual | Answer directly, then add a witty observation |
| Mathematical | Compute and move on |

## Attention Management Checklist

Before answering interruption:
- [ ] Note your current position (which stotra? which pāda?)
- [ ] Note first word of next planned pāda
- [ ] Answer question
- [ ] Recall position and continue

## Composure Phrases

If thrown off:
- "Let me consider..." (buys 3 seconds)
- Smile and return to the verse
- If you truly forgot, acknowledge and move forward — never bluff
