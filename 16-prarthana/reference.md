## Prayer Template Library

### Simple Plea
```
he [deity-voc]!
[imperative] mām!
```

### Extended Prayer
```
he [deity-voc]! he [epithet-voc]!
śṛṇu mama prārthanām.
[request 1 — dehi/kuru + object]
[request 2 — rakṣa/pāhi + mām + ablative]
[request 3 — naya/darśaya]
tava śaraṇam prapadye.
```

### Benedictive Chain
```
[deity] pātu [body part / quality]
[deity] rakṣatu [situation]
[deity] [benediction]
sarve bhavantu sukhinaḥ.
```
