| Suffix | Function | Example |
|--------|----------|---------|
| -ta | past participle | √kṛ → kṛta (done) |
| -ti | abstract F noun | √bhaj → bhakti |
| -ana | action N noun | √darś → darśana |
| -tṛ | agent | √kṛ → kartā (doer) |
| -ya | "to be X" | √pūj → pūjya |
| -in | "having X" | √yuj → yogin |
| -man | instrument/result | √kṛ → karman |
| -tra | instrument | √man → mantra |
| -tva | abstract N noun | √deva → devatva |
