# Stage 9: Dhātu — Roots and Upasargas

## Goal
Understand verbal roots (dhātus) as the atomic units of Sanskrit meaning, and learn how upasargas (prefixes) transform them systematically. See the semantic architecture hidden inside sacred vocabulary.

## What is a Dhātu?

A **dhātu** (धातु) is a verbal root — the irreducible seed from which verbs, nouns, adjectives, and entire families of words grow. Pāṇini's Dhātupāṭha lists ~2000 roots. Mastering even 50 core roots unlocks thousands of words.

## Upasargas (Prefixes)

Sanskrit has 22 traditional upasargas that modify root meanings:

| Upasarga | Core Meaning | Example with √gam |
|----------|-------------|-------------------|
| pra- | forth, forward | pragacchati (goes forth) |
| parā- | away, back | parāgacchati (goes away) |
| apa- | away, off | apagacchati (departs) |
| sam- | together, fully | saṃgacchati (comes together) |
| anu- | after, along | anugacchati (follows) |
| ava- | down | avagacchati (understands) |
| nis- | out, away | nirgacchati (goes out) |
| dur- | bad, hard | durgama (hard to go) |
| abhi- | toward | abhigacchati (approaches) |
| adhi- | over, upon | adhigacchati (attains) |
| su- | good, well | sugama (easy to go) |
| ut- | up | udgacchati (rises) |
| ati- | beyond | atigacchati (transcends) |
| vi- | apart, special | vigacchati (separates) |
| ā- | toward, back | āgacchati (comes) |
| prati- | toward, against | pratigacchati (returns) |
| pari- | around | parigacchati (goes around) |
| upa- | near | upagacchati (approaches) |

## The Mantra of Meanings: √grah as Example

**√grah** (to seize/grasp):

| Prefix + Root | Word | Meaning | Shift |
|--------------|------|---------|-------|
| grah | graha | planet (that seizes) | basic |
| anu + grah | **anugraha** | grace, favor | "seize after" → bless |
| ni + grah | **nigraha** | restraint, control | "seize down" → subdue |
| sam + grah | **saṃgraha** | collection | "seize together" → gather |
| pari + grah | **parigraha** | acceptance, embrace | "seize around" → surround |
| vi + grah | **vigraha** | conflict, form | "seize apart" → separate |
| upa + grah | **upagraha** | satellite, support | "seize near" → assist |
| pra + grah | **pragraha** | rein, control | "seize forward" → guide |

From one root, an entire philosophical vocabulary blooms.

## Kṛt-pratyayas (Root Suffixes)

These suffixes attach to dhātus to create new words:

| Suffix | Creates | Example |
|--------|---------|---------|
| -ta / -na | past participle | kṛta (done), datta (given) |
| -ti | abstract noun (F) | bhakti, śakti, mukti |
| -ana | action noun (N) | darśana, smaraṇa |
| -tṛ | agent noun | kartā (doer), dātā (giver) |
| -ya | gerundive ("to be X") | pūjya (to be worshipped) |
| -in | possessor | yogin (one who has yoga) |

## Milestone Check

Given a word like "anugraha," can you identify the root (√grah) and prefix (anu-), and explain how the meaning shifts? Can you see the semantic architecture in at least 10 sacred words?

### 🧱 New Bricks Learned

| Brick Type | Examples | Snaps onto... |
|------------|----------|---------------|
| Root bricks | √kṛ (do), √bhū (be), √gam (go), √dā (give), √nam (bow), √bhaj (serve) | Everything — roots are the atomic meaning-units from which verbs, nouns, and adjectives all grow; every verb-brick you have used since Stage 1 is a root brick in disguise |
| Prefix bricks (upasarga) | pra- (forth), ā- (toward), sam- (together), vi- (apart), anu- (after), upa- (near) | Snap onto root bricks to shift meaning: pra+√nam = praṇam (bow forth), ā+√gam = āgam (come toward), sam+√gam = saṃgam (come together) |

**Try snapping**: Pick a single root brick like √hṛ (to take) and snap on four different prefix bricks — anu+hṛ (anugraha, grace), vi+hṛ (vihāra, sport), pra+hṛ (prahāra, strike), sam+hṛ (saṃhāra, destruction) — then use each derived word in a devotional sentence with kāraka connectors from Stage 7.
