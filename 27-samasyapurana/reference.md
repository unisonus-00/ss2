# Stage 27: Samasyāpūraṇa — Reference Guide

## Problem-Solving Approaches

| Approach | When to Use | Example |
|----------|------------|---------|
| Mythological | Pāda describes impossible physical feat | "drank poison" → Śiva/hālāhala |
| Philosophical | Pāda contains paradox | "formless yet formed" → Brahman |
| Śleṣa (double meaning) | Words have multiple meanings | "go" = cow/earth/speech |
| Sandhi re-analysis | Break words differently | "tapobhiḥ" → tapaḥ + abhiḥ or tapo + bhiḥ |
| Metaphorical | Literal reading absurd | "fire" = anger, "ocean" = saṃsāra |
| Narrative twist | Set up a story context | Begin with "once upon a time..." |

## Composition Checklist for Samasyāpūraṇa

1. ☐ Given pāda: note exact syllable count and pattern
2. ☐ Identify meter (usually anuṣṭubh)
3. ☐ Find a context that naturalizes the given pāda
4. ☐ Compose pāda a (set the scene)
5. ☐ Compose pāda b (develop)
6. ☐ Compose pāda c (transition to the given pāda)
7. ☐ Given pāda falls naturally as conclusion
8. ☐ Verify meter in all 4 pādas
9. ☐ Check that the whole verse is coherent
