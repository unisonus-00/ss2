# Stage 29: Niṣiddhākṣarī — Reference Guide

## Substitute Words When Common Letters Are Forbidden

### Without "na" (न)
| Blocked | Substitutes |
|---------|------------|
| namāmi | bhajāmi, staumi, vandāmi |
| namaḥ | jayatu, stuti |
| nīlakaṇṭha | use śambhu, hara, mahādeva |
| candra | indu, śaśī, vidhu |
| mandira | ālaya, kṣetra |
| nandī | vṛṣabha |
| ananta | aprameya, aśeṣa |
| sundara | rucira, cāru, śobha |

### Without "ma" (म)
| Blocked | Substitutes |
|---------|------------|
| namāmi | stauti (3P), bhajati (3P), vandāvahe |
| mama | asya (his — rephrase to 3P) |
| -am ending | use other cases |
| mantra | vidyā |
| mandira | ālaya |
| mokṣa | kaivalya |

### Without "sa" (स)
| Blocked | Substitutes |
|---------|------------|
| sarvam | akhilam, viśvam |
| sadā | nityam |
| sundara | rucira, cāru |
| sarasvatī | vāgdevī, bhāratī, śāradā |
| stotra | gīti, stuti |

### Without "ka" (क)
| Blocked | Substitutes |
|---------|------------|
| kṛṣṇa | hari, govinda, mādhava |
| kṛpā | dayā, prasāda |
| kamala | padma, aravinda, paṅkaja |
| karuṇā | dayā |
| kartā | dhātā |

## Checking Process

1. Write your verse
2. Read EVERY syllable aloud
3. Mark any occurrence of the forbidden letter with ✗
4. Replace the offending word
5. Re-check the replacement
6. Repeat until clean

## Quick Phonological Awareness

Sanskrit consonant chart — know where each sound lives:
```
ka kha ga gha ṅa   (kaṇṭhya - guttural)
ca cha ja jha ña   (tālavya - palatal)
ṭa ṭha ḍa ḍha ṇa  (mūrdhanya - retroflex)
ta tha da dha na   (dantya - dental)
pa pha ba bha ma   (oṣṭhya - labial)
ya ra la va        (antaḥstha)
śa ṣa sa ha        (ūṣman)
```
