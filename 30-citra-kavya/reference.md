# Stage 30: Citra-kāvya — Reference Guide

## Multi-Constraint Planning Template

```
CONSTRAINTS:
1. Meter: ___ (syllables per pāda: ___)
2. Deity: ___ (available epithets: ___, ___, ___)
3. Rasa: ___ (vocabulary bank: ___, ___, ___)
4. Required word: ___ (syllable pattern: ___)
5. Forbidden letter: ___ (blocked words: ___, ___, ___)
6. Required alaṅkāra: ___

PLAN:
- Integrate required word via: [upamā / rūpaka / direct / narrative]
- Rasa vocabulary choices: ___
- Epithet choices (avoiding forbidden letter): ___
- Line-by-line sketch: ___

VERIFY:
☐ Meter  ☐ Deity  ☐ Rasa  ☐ Word  ☐ Letter  ☐ Alaṅkāra
```

## Constraint Interaction Matrix

| If constrained by... | Be flexible with... |
|---------------------|---------------------|
| Meter (strict) | Word choice, synonyms |
| Forbidden letter | Synonyms, rephrasing |
| Required word | Where it falls in the verse |
| Required rasa | Vocabulary, sentence type |
| Required alaṅkāra | Where in the verse it appears |

## Order of Constraint Satisfaction

1. **Fixed constraints first:** meter pattern, forbidden letter
2. **Place the required word** — find where it fits metrically
3. **Build around it** — deity reference, rasa vocabulary
4. **Add the alaṅkāra** — weave in simile/metaphor
5. **Final check** — verify ALL constraints simultaneously

## Emergency Techniques

| Problem | Solution |
|---------|----------|
| Required word doesn't fit meter | Change its case form / use a compound |
| Can't avoid forbidden letter in key word | Use a completely different synonym |
| Rasa conflicts with deity | Find an aspect of the deity that matches |
| Alaṅkāra feels forced | Make it the central image, not an add-on |
| Too many constraints at once | Satisfy the hardest 2 first, then adjust |
